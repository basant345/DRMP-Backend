DRMP deployment dataset  -  trimmed vectors + compressed DEM
============================================================
Drop-in replacement for drmp_app/data. 826 MB -> 139 MB on disk.
Every file the backend opens is present. No information removed.

    LOSSLESS. Verified pixel-exact against the original across all

ONE BEHAVIOUR CHANGE
  /api/dem/info reads a downsampled overview instead of averaging full
  resolution, so its summary shifts slightly:
      mean   157.2753 -> 157.2809   (+0.006 m)
      std    231.6991 -> 231.3474
      min/max smoothed by overview averaging
  Point elevation (/api/dem/sample), profiles and tiles read full-resolution
  pixels and are completely unaffected.
  To make /api/dem/info byte-identical too, rebuild with OVERVIEWS='NONE'.

INSTALL
  Replace drmp_app/data with the data folder in this archive.
  Set DATA_DIR to the absolute path of .../data/DRMP/Input
  Verify at /api/layers/available  ->  all 7 entries "exists": true
